# c2c-cybersecurity-CTF-sprint

This cybersecurity capstone project features 8 picoCTF challenges, 15 OverTheWire Bandit challenges, and an AI-usage log for said challenges. The AI assistant used was GitHub Copilot and it provided Socratic hints towards difficulties faced during the challenges. The picoCTF challenges range from Linux and Cryptography to Web Exploits while the OverTheWire Bandit challenges range from finding content in files to utilizing ports to complete a challenge.

## Reflection:
I have learned much more about the uses of Linux beyond just Flatpak and downloading applications. The Linux terminal is very powerful, allowing the user to go beyond just surface-level applications, especially in cybersecurity. I have learned about web exploits (i.e. robots.txt), using Linux commands to execute certain files, and cryptography with images. The hardest challenge I had was OverTheWire Bandit 13 where I had to find the password in a repeatedly compressed hexdump file. The AI assistant provided hints to research certain topics that were related to my challenges (like looking up the "robots exclusion protocol"), but was not allowed to provide me direct answers and solutions.

Bandit 14, Linux/general. What it asked: Find the password stored in /etc/bandit_pass/bandit14 that can only be read by user bandit14. What I tried: Used ls to list file names, exited the connection, logged out, and used an scp command to connect to the remote machine. What worked: Used scp -P with the typical OverTheWire Bandit key (changing the number to 13) and using :sshkey.private. The password for it is also sshkey.private. I had to reduce the permissions with chmod 700 sshkey.private and eventually used the key to log into the port. Concept learned: scp is a command that uses SSH to transfer data. chmod 700 can be used to reduce permissions to obtain certain access to files and information. Assistant: N/A

Bandit 5, Linux/general. What it asked: Find the password for level 5 from a human-readable file in the directory inhere. What I tried: Used ls to list file names, cd inhere to get into the directory, used ls again to list the directory's files, ls -la for all ten files listed, then cat file* and cat -- -file* to list the contents of the files, then file ./* to list the data types held in the files. What worked: Using file ./* to list the file content, then cat ./-file07 to get the password. Concept learned: ls -la for all files listed, * is a wildcard, file ./* to list file datatypes.

Bandit 7, Linux/general. What it asked: Find a file on the server owned by user bandit7, group bandit6, and 33 bytes in size. What I tried: Used ls to list file names, then used ls -l to list user and group names for ownership, then tried to use a giant find command that didn't work, so I added 2>/dev/null to it. What worked: The fine command with the 2>/dev/null appended to it, retrieved the password.

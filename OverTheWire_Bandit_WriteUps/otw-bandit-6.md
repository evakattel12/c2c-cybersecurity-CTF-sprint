Bandit 6, Linux/general. What it asked: Find the password for level 6 using a file in the inhere directory that has the properties of being human-readable, 1033 bytes in size, and not executable. What I tried: Used ls to list file names, used cd to move into the inhere directory, then used file */{.,} | grep ASCII to get ASCII files only, then used one command to find a very sepcific file, that is find . type -f -size 1033c | -excutable -exec file "{}" \; | grep ASCII. What worked: Using that one whole command did all of the work that many lines of commands would've done.
